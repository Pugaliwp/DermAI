Workflow

How The Screening Process Works

1

Upload Image

Take a clear, close-up photo of the affected skin area (JPG, JPEG, PNG) and upload it.

2

Feature Extraction

The Python FastAPI microservice extracts color distribution, asymmetry, border irregularity, and texture features.

3

AI Prediction

The neural network matches patterns against disease profiles (Melanoma, Eczema, Psoriasis, etc.).

4

Report & Action

View recommendations, review educational disease details, and export your PDF report.

About DermAI

Empowering Early Skin Health Awareness

DermAI is an open full-stack web solution designed to bridge the gap between artificial intelligence and preliminary medical triage. By using modern web architecture (Node.js Express backend, Python FastAPI AI engine, and MySQL storage), it demonstrates how AI can democratize health awareness.

  • Modular MVC Architecture
  • Strict Data Validation & Encryption
  • Comprehensive Admin Analytics & Control
